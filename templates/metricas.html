{{ icon('flask') }}Por qué se muestran por clase

El conjunto de evaluación tiene tantos positivos como negativos. En ese caso, promediar precisión, recall y F1 de las dos clases según su tamaño da prácticamente la accuracy (el recall promediado así es exactamente la accuracy), y las cuatro cifras parecen iguales. Separadas por clase muestran en qué se equivoca cada modelo.

Cómo se calculan

Las fórmulas se escriben para la clase positiva; para la negativa se intercambian los papeles. \(TP\) son positivos bien clasificados, \(TN\) negativos bien clasificados, \(FP\) negativos clasificados como positivos y \(FN\) positivos clasificados como negativos.

Accuracy
\(\displaystyle \text{Accuracy} = \frac{TP + TN}{TP + TN + FP + FN}\)Proporción de tweets clasificados correctamente. Con clases equilibradas, el azar obtendría 0.50.
Precisión
\(\displaystyle P = \frac{TP}{TP + FP}\)De los tweets marcados como positivos, cuántos lo eran realmente.
Recall
\(\displaystyle R = \frac{TP}{TP + FN}\)De los tweets positivos reales, cuántos se detectaron.
F1
\(\displaystyle F_1 = \frac{2 \cdot P \cdot R}{P + R}\)Media armónica de precisión y recall. Se calcula para cada clase.
Intervalo de confianza
\(\displaystyle \frac{\hat{p} + \frac{z^2}{2n} \pm z\sqrt{\frac{\hat{p}(1-\hat{p})}{n} + \frac{z^2}{4n^2}}}{1 + \frac{z^2}{n}}, \quad z = 1.96\)Intervalo de Wilson: rango en el que se encontraría la accuracy real con un 95 % de confianza.
